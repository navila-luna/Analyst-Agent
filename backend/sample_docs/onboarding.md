# New Engineer Onboarding

## Day 1
Get your laptop set up with the standard dev image. IT will provision your accounts
for GitHub, Slack, and the internal wiki within the first 24 hours. Ask your manager
for access to the team's private Slack channel.

## Repo access
All backend services live in the `platform` GitHub organization. Request access via
the #it-access Slack channel; approval usually takes under an hour during business
hours.

## Local environment
Install Python 3.11+ and Node 20+. Use `pyenv` and `nvm` to manage versions per
project rather than a single system-wide install, since different services pin
different versions.

## First week goals
- Ship one small PR (doc fix or minor bug) by day 3
- Shadow an on-call engineer for at least one incident review
- Read the "Runbook: Deploying a Service" doc before your first deploy

## Equipment
New hires get a laptop, monitor, and a $300 home-office stipend for peripherals.
